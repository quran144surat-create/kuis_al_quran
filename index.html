🔒 Aman kok. Kedua pilihan di atas tidak mengirim datamu ke pihak lain. "Tanpa database" tersimpan di HP/browser ini sendiri. "Buat Sheet sendiri" tersimpan di akun Google-mu sendiri — aplikasi ini tidak pernah menyimpan atau melihat isi catatanmu di server mana pun.

🔒 Amankah data saya?
Bisakah pembuat aplikasi ini melihat catatan hafalan saya?
Tidak bisa. Kalau kamu pilih "Buat Sheet sendiri", datamu tersimpan di Spreadsheet dan skrip milikmu sendiri — bukan di server siapa pun, dan pembuat aplikasi ini tidak punya akses ke sana. Kalau pilih "Tanpa database", data cuma ada di HP/browser ini, tidak terkirim ke mana-mana.
Apakah saya harus memasukkan password Google saya?
Tidak pernah. Aplikasi ini tidak akan meminta kamu mengetik password Google di mana pun.
Kenapa Google menampilkan peringatan "aplikasi ini belum diverifikasi"?
Itu wajar dan aman untuk skrip pribadi yang kamu buat & jalankan sendiri — mirip peringatan saat membuka file yang baru diunduh, bukan tanda virus atau penipuan.
Bisakah saya membatalkan izin ini nanti kalau berubah pikiran?
Bisa, kapan saja. Buka myaccount.google.com/permissions di akun Google-mu, cari nama skrip/deployment-nya, lalu cabut aksesnya.
📖 Istilah yang dipakai
Google Sheet
Semacam buku catatan/Excel online dari Google, dipakai di sini untuk menyimpan data hafalanmu.
Apps Script
Skrip kecil dari Google yang membaca dan menulis data ke Sheet-mu atas nama kamu sendiri.
Deployment
Proses "menerbitkan" skrip tadi supaya bisa dipakai lewat sebuah alamat (URL) khusus.
Izin akses (permission)
Persetujuan yang kamu berikan supaya skrip boleh membaca/menulis Sheet-mu. Data ini tetap milikmu sepenuhnya.
Sinkronisasi
Proses data di HP dan di Sheet dibuat sama/terbaru secara otomatis.

Otomatis

Belum tersedia

Masuk dengan akun Google, lalu Sheet dibuat otomatis untukmu — paling mudah untuk kebanyakan orang. Pilihan ini belum tersedia; pilih Manual dulu, atau pakai Tanpa database untuk sekarang.

Manual / Lanjutan

Untuk yang mau kontrol penuh: deploy skrip Apps Script sendiri, lalu tempel URL web app-nya di sini.

Kunci wajib. Tanpa kunci, siapa pun yang tahu URL bisa membaca dan mengubah catatanmu.

Belum punya skrip? Lihat langkah & salin kode
  1. Buka sheets.google.com → buat spreadsheet baru (nama bebas).
  2. Menu Extensions → Apps Script.
  3. Hapus semua isi editor kode (file Code.gs), lalu tempel Bagian 1 di bawah. Klik + di samping Files → Script, beri nama Code2, hapus isinya, lalu tempel Bagian 2. Simpan keduanya.
  4. Deploy → New deployment → klik ikon gerigi ⚙️ → pilih Web app.
  5. Isi Execute as: Me dan Who has access: Anyone → klik Deploy → Authorize access. Kalau muncul peringatan "Google hasn't verified this app", klik Advanced/Lanjutan → klik nama aplikasi untuk melanjutkan. Ini wajar untuk skrip pribadi.
  6. Wajib: di editor, pilih fungsi setupKeys → Run. Buka Execution log, salin KUNCI PRIBADI ke kolom kunci di atas. KUNCI KOMUNITAS hanya untuk dibagikan ke guru lain.
  7. Salin Web app URL yang muncul, tempel di kolom di atas. Lebih mudah: di editor pilih fungsi kirimLinkKeEmail → Run (setujui izin email). URL dan kunci dikirim ke emailmu, tinggal salin dari email.

Penting: tanpa kunci (setupKeys), siapa pun yang punya URL web app bisa membaca/mengubah isi Sheet-mu. Jaga URL dan kuncinya seperti kata sandi.

Opsional: rekap detail untuk link progres 1 santri (Bagian 3)

Tidak wajib — tanpa ini semua tetap jalan normal. Bagian ini hanya menambah data riwayat pada link progres 1 santri spesifik, dipakai kalau nanti ada tampilan rekap (grafik/tabel per periode) di halaman publik. Tidak mengubah Code.gs maupun Code2 yang sudah ditempel di atas.

  1. Pastikan Bagian 1 (di Code.gs) dan Bagian 2 (di file Code2) di atas sudah ditempel & disimpan lebih dulu.
  2. Klik + di samping Files → Script, beri nama Code3, hapus isinya, lalu tempel kode di bawah. Simpan.
  3. Deploy ulang setelahnya: Deploy → Manage deployments → ikon pensil → New version → Deploy.

Kunci akses skrip

Isi kalau skripmu sudah memakai kunci (jalankan setupKeys di Apps Script). Kunci pribadi jangan dibagikan.

Email dikirim dari skripmu sendiri ke email akun Google pemilik Sheet, jadi tidak ada data yang disimpan di pihak lain. Butuh Code.gs terbaru yang sudah di-deploy.

Bagikan progres (lihat saja)

Di dalam tautan ini ada nama dan catatan hafalan seseorang. Mohon bagikan hanya kepada orang-orang terdekat yang berhak tahu, agar privasi santri tetap terjaga.

Filter sebelum bagikan (opsional)

Setelah lewat, halaman rekap akan menampilkan pesan "tautan kedaluwarsa" alih-alih data — dicek dari jam HP yang membuka link, bukan lewat server.

Komunitas guru — tambahkan link Apps Script guru lain untuk melihat gabungan progres semua santri di tab "Komunitas". Tab itu muncul otomatis begitu ada minimal satu sumber, dan hilang lagi kalau semua sumber dihapus.

Fitur tambahan: rekap detail per-santri

Tidak wajib — tanpa ini semua tetap jalan normal. Bagian ini hanya menambah data riwayat pada link progres 1 santri spesifik, dipakai kalau nanti ada tampilan rekap (grafik/tabel per periode) di halaman publik. Tidak mengubah Code.gs maupun Code2 yang sudah ada.

  1. Buka Apps Script proyekmu (dari Google Sheet: Extensions → Apps Script). Pastikan Bagian 1 (Code.gs) dan Bagian 2 (Code2) yang lama tidak diubah/dihapus.
  2. Klik + di samping Files → Script, beri nama Code3, hapus isinya, lalu tempel kode di bawah. Simpan.
  3. Deploy ulang setelahnya: Deploy → Manage deployments → ikon pensil → New version → Deploy.
